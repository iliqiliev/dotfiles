# uBlock Origin settings

The `my-ublock-backup.txt` file contains all uBlock settings.  
**Do not restore** them from it if you don't want your
personal settings being **overwritten**!

# Usage

- Go to uBlock Origin's extension settings
- Scroll down on the main tab (_Settings_)
- Click the `Restore from file…` button
- Navigate to `~/.config/ublock-origin`
- Select `my-ublock-backup.txt` and press `OK`
